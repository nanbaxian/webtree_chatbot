# Webtree Academy — Website + PDF Archive

Archive date: 2026-04-19
Source site: https://www.webtreeedu.com/

## Scope
This file consolidates publicly accessible information from the Webtree Academy website and the PDF documents discoverable from the site at the time of capture.

Included in this archive:
- Core website navigation and key public pages
- Contact and admissions information
- Tuition and fee information visible on the website
- PDF inventory discovered from the site
- Full text extraction available from the View Book PDF
- Structured extraction from the 2024–2025 and 2025–2026 school calendars
- Partial extraction / summary for newsletters and brochure PDFs where available

Limitations:
- Some newsletter PDFs could be located publicly but did not expose full text reliably through the available retrieval path.
- Some pages contain images, layouts, or embedded design elements that do not fully convert into text.
- This is a content archive, not a perfect visual mirror of the website.
